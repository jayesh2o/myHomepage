# My Portfolio Website

* A dark-themed personal website which I built so that I could showcase my projects, interests, and hobbies.

Features:
Dark Navy Astetics: Has a Dark Navy color pallet with orange, white, and grey text.
Interactive Elements: Has card lift animations which get activated whenever your cursor hovers over a card.
Navbar with multiple pages: Has a Navbar with multiple pages which indicates what page your currently on.

Was built with mostly HTML & CSS, however a little bit of Javascript was also incorperated for the Navbar.

Pages Overview:
index.html - Home: Is the main page of the website which features a quick mention of things I like to do along with hyperlinks to other potions of the website.
about.html - About: Showcases my journey through programming and how I started off, along with what I enjoy to do now when programming.
projects.html - Projects: Showcases the projects that I'm currently working on, with links to the projects, captions explaining them, and indicators to represent their status. However, currently the only thing on there is the portfolio website as its still one of my projects.

I'm most proud of the interactive elements as it's really facinating to me that you can use transitions to make the viewer feel more welcome and engaged.
